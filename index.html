Wzory i haczyki

Stosunki (bez odniesienia)

Moc: dB = 10 log₁₀(P₂/P₁)
P₂/P₁ = 10^(dB/10)

Napięcie: dB = 20 log₁₀(U₂/U₁)
U₂/U₁ = 10^(dB/20)

Poziomy (z odniesieniem)

dBW = 10 log₁₀(P[W])
dBm = 10 log₁₀(P[mW])
dBV = 20 log₁₀(U[V])
dBµV = 20 log₁₀(U[µV])
dBm = dBW + 30

W drugą stronę

P[W] = 10^(dBW/10)
P[mW] = 10^(dBm/10)
U[V] = 10^(dBV/20)
U[µV] = 10^(dBµV/20)

Na pamięć

+3 dB ≈ ×2 mocy
+6 dB ≈ ×2 napięcia
+10 dB = ×10 mocy
+20 dB = ×10 napięcia
0 dB = bez zmiany

Uwaga 1: dBm + dBm nie jest zwykłą sumą! 0 dBm + 0 dBm dla niezależnych mocy = 3,01 dBm.
Uwaga 2: kaskadowe zyski/straty w dB możesz sumować.
Uwaga 3: P = U²/R wymaga znajomości oporu i napięcia RMS.
Uwaga 4: ujemne dBm nie oznacza ujemnej mocy.

Stworzone do ćwiczeń na podstawie materiałów z decybeli • Wartości ±3 i ±6 dB traktuj jako przybliżone.
